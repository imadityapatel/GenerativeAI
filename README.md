# Generative AI Academy

Responsive standalone learning website with a left sidebar and click-to-display lesson content.

## Includes
- 100 classes with detailed notes and learning outcomes
- Complete runnable Python standard-library concept demonstrations and expected output for every class
- 30 embedded SVG diagrams
- 6 applied case studies
- Books, online references, future trends, company resources, instructor profile, and suggestions form

## Run locally
Open `index.html` in a modern browser. No build step is required.

## Publish with GitHub Pages
Upload `index.html`, `README.md`, and `.nojekyll` to the repository root. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

## Important
Programs are deterministic local teaching demonstrations, not production model calls. For hosted model use, configure a provider SDK, API key, budget limits, and privacy controls. Never commit API keys to GitHub.
